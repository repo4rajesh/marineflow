# MarineFlow.ai

A modern web application for maritime intelligence and AI-powered maritime efficiency solutions.

## Overview

MarineFlow.ai is a Next.js-based web application that provides maritime intelligence solutions powered by artificial intelligence. The application features a modern, responsive design with various components including:

- Interactive Hero section
- Feature showcase
- Case Studies
- Statistics dashboard
- Testimonials
- Contact form
- Responsive navigation

## Tech Stack

- **Framework**: Next.js 14.1.0
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Heroicons
- **UI Components**: Custom React components
- **Images**: SVG and optimized images

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/repo4rajesh/marineflow.git
```

2. Install dependencies:
```bash
cd marineflow
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
